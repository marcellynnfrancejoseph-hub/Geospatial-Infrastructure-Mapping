# Geospatial Infrastructure & Network Mapping
**Technical Specialist:** Marcel Joseph

This repository demonstrates advanced proficiency in converting legacy cartographic assets into high-fidelity, attribute-rich vector datasets using **QGIS 3.x**.

## Featured Project: Kent County Transit Modernization
Successfully transformed a non-spatial regional transit map into a topologically sound GeoPackage for infrastructure optimization.

### Key Skills Demonstrated:
* **Georeferencing:** Spatial alignment of raster assets using GCPs.
* **Vectorization:** Manual digitization of linear infrastructure (LineString geometry).
* **Topology Enforcement:** Ensuring connectivity and node integrity at transit hubs.
* **Attribute Management:** Schema-compliant metadata capture for AI/ML readiness.
